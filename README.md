# 🤖 Qwen-бот для Telegram — минимализм

Универсальный ИИ-бот на Qwen 3.8 27B (Groq). Никаких лишних кнопок — работает как обычный чат.

- Приветствие: «Что вас интересует, *имя*?»
- Одна кнопка: **🆕 Начать новый чат** (старая история стирается, ничего не храним)
- Никаких команд, кроме `/start` — просто пишешь текст
- Инструменты бот понимает сам, в диалогом:
  - «сгенерируй фото ...» → нарисует и пришлёт картинку
  - «что с погодой/новости/цены» → поищет в интернете
- Понимает 🎤 голосовые и 📷 фото с подписью
- Модель одна — Qwen, выбирать ничего не нужно

## Запуск локально (Windows)

`start.bat` (первый раз сам создаст окружение). Ключи — в `.env`:

```
BOT_TOKEN=...
GROQ_API_KEY=...
```

## Запуск на бесплатном сервере

Пошаговая инструкция: **DEPLOY.md** (Hugging Face Spaces, Docker, всё бесплатно).

## Структура

```
tgbot/
  __main__.py    — запуск: поллинг + health-порт для хостинга
  config.py      — настройки из .env
  db.py          — SQLite: один активный диалог на пользователя
  groq_api.py    — клиент Groq (стриминг, tool calls, ретраи, фолбэки, аудио)
  core.py        — конвейер: модель → инструменты (картинки/поиск) → стрим в TG
  handlers.py    — обработчики Telegram
  prompts.py     — системный промпт + описание инструментов
  ui.py          — клавиатура, отправка/правка сообщений
  websearch.py   — поиск (ddgs + фолбэк), выкачивание страниц
Dockerfile       — образ для бесплатного хостинга
DEPLOY.md        — инструкция деплоя
data/bot.db      — локальная база (создаётся сама)
```

## Важно 🔐

- Не выкладывай ключи (`.env`) в публичные места — при утечке перевыпусти их в @BotFather и console.groq.com.
- Запускай только **один** экземпляр бота (локальный + серверный одновременно = конфликт).
