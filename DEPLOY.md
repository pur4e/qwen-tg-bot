# 🚀 Как запустить бота на бесплатном сервере (5 минут)

Бот перестанет зависеть от твоего ПК. Используем **Hugging Face Spaces** —
бесплатный хостинг Docker-приложений (2 vCPU, 16 ГБ RAM — бот потребляет копейки).

⚠️ **Перед стартом останови бота, который крутится локально** (окно `start.bat` / текущая
сессия). Две копи на один токен бота воюют между собой.

## Шаг 1. Аккаунт

1. Зайди на **https://huggingface.co** → Sign Up → email + пароль, подтверди почту.
2. Токены Hugging Face не нужны — только аккаунт.

## Шаг 2. Создать Space

1. Сверху справа: **New → Space**.
2. Название: `tg-qwen-bot` (или любое).
3. SDK: выбери **Docker** (Blank).
4. **Visibility: Private** — важно (в приватном Space никто не увидит код).
5. Нажми **Create Space**.

## Шаг 3. Залить файлы

На вкладке **Files** нового Space: кнопка **Add file → Upload files**.

Перетащи в окно загрузки:
- `Dockerfile`
- `requirements.txt`
- все файлы из папки `tgbot` (10 файлов `*.py`)

Ниже в поле Commit changes напиши «init» → **Commit changes**.
Сборка сразу сломается — это нормально, нет ключей. Идём дальше.

## Шаг 4. Секреты (твои ключи)

**Settings** Space (вкладка справа вверху) → раздел **Variables and secrets** →
**New secret**, добавь два:

| Name | Value |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (`8686...`) |
| `GROQ_API_KEY` | ключ `gsk_...` |

Secrets надёжно спрятаны: их никто не увидит.

## Шаг 5. Перезапуск и проверка

Settings → **Factory reboot** (или вкладка Build → behaviour перезапустится сама).
Через 1–2 минуты статус станет **Running**. Открой бота в Telegram и напиши ему 🎉

## Обслуживание

- **Логи бота**: вкладка **Logs** Space (смотри сюда, если что-то не так).
- **Изменить код**: Files → открой файл → Edit → Commit — Space пересоберётся сам.
- **Полный перезапуск**: Settings → Factory reboot.
- **Остановить**: Settings → Pause Space.
- **Лимиты бесплатного**: базовый CPU бесплатен; контейнер спокойно живёт, пока бот
  активен. Если Space «уснул» (нет активности ~48 ч) — просто Factory reboot.
- **База истории диалогов** живёт внутри Space со стилем «минимализ» и обнуляется при
  перезапуске — для этого бота это нормально (кнопка «Новый чат» всё равно стирает историю).

## Почему не другой хостинг

| Сервис | Почему нет |
|---|---|
| Heroku, Railway, Fly.io | бесплатного тарифа больше нет (нужна карта) |
| Render | фоновые процессы только платно, веб спит через 15 мин |
| PythonAnywhere | always-on только на платных тарифах |
| Oracle Cloud VPS | реально бесплатный и мощный, но регистрацию часто отклоняют (нужна карта) |

HF Spaces — самый простой и честно бесплатный вариант. Если захочешь «посерьёзнее»
(24/7 без ограничений, своя БД) — расскажу про VPS за ~$5 или Oracle Free, но для этого
бота хватит и Space.
